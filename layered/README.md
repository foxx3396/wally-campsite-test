# 006 캠핑장 · 공유 캐릭터 장면
[게임 열기](https://foxx3396.github.io/wally-campsite-test/layered/)

목적: 원화 캠핑장 구도를 참고한 움직이는 숨은그림찾기. 휠이나 확대 버튼으로 살펴보고, 드래그로 이동한 뒤 월리를 클릭한다. 인물 실루엣의 불투명 픽셀을 기준으로 선택하며 성공 시 탐색 시간을 표시한다. 힌트와 다시 찾기를 지원한다.

입력은 인물이 없는 복원 배경과 분리한 식생·강물·구조물·캐릭터 원본 PNG다. 출력은 1,526 × 1,031 Canvas 장면이다. 건물과 캐릭터는 깊이순으로 그린다. 풀과 물의 움직임은 각 레이어의 알파 영역 안에만 표시한다. 레이어 체크박스로 분리 상태를 확인할 수 있다.

411개 인물·동물 배치는 32개 외형과 11개 동작을 공유한다. scene.json에는 샘플 키, 위치, 크기, 반전, 색, 동작 진폭, 시작 프레임이 들어간다. 같은 샘플과 색 조합은 한 번만 준비한다. 공용 타임라인은 각각 100칸(10fps × 10초)으로, 관절 각도나 스프라이트 포즈를 지정한다. 캐릭터마다 100장씩 저장하지 않는다. 월리는 전용 외형을 쓴다.

실행 시 네 장의 WebP, 투명 스프라이트 시트 한 장, scene.json을 요청한다(합계 약 3.76 MB, HTML/JS/CSS 제외). 편집용 PNG와 inventory.json은 게임 로딩에 포함하지 않는다.

검증: 실제 Canvas 엔진에서 0번과 40번 프레임의 픽셀 차이, 411개 동작 연결, 100칸 길이, 모든 레이어를 끄면 불투명 픽셀이 0개임을 확인했다. 월리 실루엣 클릭과 재시작도 통과했다.

한계: 원작 인물 수나 원작의 전체 포즈를 복원한 것이 아니다. 군중 위치에 유사 샘플을 배치한 재구성이며 작은 인물의 겹침과 가려진 디테일은 원화와 다를 수 있다. 네이티브 4K가 아니며 슬라이더의 100칸은 100장의 서로 다른 손그림을 뜻하지 않는다.
