# 캠핑장 레이어 제작실 — V3 작업본

실행: https://foxx3396.github.io/wally-campsite-test/layered/

## 목적
단일 배경 위에 새 캐릭터를 얹던 V2에서, 원래 장면의 배경·식생·물·구조물·캐릭터를 분리한 합성 구조로 전환한다.

## 실제 완료 범위
- 이미지 생성 도구로 사람·동물을 제거하고 가려진 지형을 복원한 clean plate 생성.
- 풀·수풀·나무, 물, 텐트·차량·배·다리, 사람·동물의 투명 레이어 생성.
- 복원 배경에서 다른 레이어의 마스크를 빼므로 레이어를 끄면 같은 내용이 배경에 남지 않는다.
- 캐릭터 관련 183개 연결 조각의 위치·픽셀 마스크를 JSON으로 기록. **183명이라는 뜻이 아니다.**
- 육안으로 고른 인물 66개·동물 7개에 100개 상태를 가진 10초·10fps 관절 동작 초안 적용. 통째로 이동하는 파형 효과는 없음.
- 나머지 110개 조각은 군중·소품·부분 인물로서 개별 분리 대기. 미완성 군중을 한 명처럼 움직이지 않음.
- 구조물 32개 영역 및 잔여 픽셀에 깊이 기준을 부여해 인물과 앞뒤 합성. 깊이값은 초안이며 겹친 군중 단위의 한계가 남음.
- 레이어 표시, 분리 조각 검사, 개별 선택, 타임라인 스크럽, 확대·이동, 목록 다운로드.

## 입력과 출력
입력: assets의 생성 PNG 5종과 inventory.json. 출력: Canvas 합성 장면, 100프레임 타임라인, 상태별 검사 UI. 원화 원본 및 V2 파일은 상위 폴더에 보존한다.

## 계산·판정
캐릭터 투명도 96 초과 픽셀을 8방향 연결 관계로 묶는다. 35픽셀 미만 또는 높이 8px 미만의 작은 조각은 목록에서 제외한다. 조각의 실제 픽셀은 행 단위 RLE로 보관한다. 따라서 사각형 안에 다른 캐릭터가 있어도 무조건 함께 잘라 그리지 않는다.
관절 동작은 각 조각에서 머리·양팔을 따로 마스킹하고 중심점을 기준으로 회전한다. 몸통에서는 해당 부분을 제외하여 중복 그림을 방지한다. 동물 초안은 머리 회전만 적용한다. 회전 키프레임 사이를 smoothstep으로 보간한 100개 상태를 저장한다. 이는 100장의 별도 수작업 포즈 그림이 아니다. 각 대상에는 시작 위상 차이를 둔다.
시간은 100ms 단위, 프레임은 0~99, 주기는 10초다. 배경 탭에서는 시간을 진행하지 않는다. 물의 유속 선과 풀잎 동작은 해당 투명 마스크 내부에서만 렌더링한다.

## 검증
- 실제 @napi-rs/canvas 렌더러로 studio.js의 합성 로직 실행.
- 183개 조각·73개 리그·리그별 100개 상태 확인.
- 0번과 40번 프레임 이미지가 다른지 확인.
- 캐릭터를 끈 렌더링을 육안 확인: 배경에 원래 캐릭터가 남지 않음.
- 5개 레이어를 모두 끄면 불투명 픽셀이 0개인지 확인: 통과.
- 전체 합성과 배경만의 렌더링 확인. 배·다리·텐트의 깊이 합성 일부 개선.
- 브라우저 직접 조작 검증과 모바일 터치 실기 검증은 미완료.

## 미완료 — 완성 장면으로 간주하지 말 것
모든 인물의 개별 분리·보이지 않는 신체 복원·자연스러운 각자 행동은 아직 완료되지 않았다. 73개도 관절 동작 **초안**으로, 목·어깨 연결과 동물별 정확한 골격을 더 조정해야 한다. 110개 검수 대기 조각의 인물 수는 확정하지 않았다. 텐트 앞뒤와 군중끼리의 가림은 추가 검수가 필요하다. 원본 화질 정보가 부족하고 생성 편집이 그림을 재해석하므로 원화의 완전한 픽셀 보존·원본 레이어 복원·네이티브 4K를 달성한 것이 아니다.

## 생성 도구와 프롬프트
내장 image_gen 편집 모드. 원본/생성 결과는 별도 파일로 보존했다.
1. clean: 같은 구도에서 모든 사람·동물을 제거하고 가려진 풀·길·물·구조물 복원.
2. characters: 원래 좌표의 모든 사람·동물만 투명 배경으로 분리. 잘못 추가된 얼굴과 배 선체를 후속 편집으로 제거.
3. grass: 잔디·수풀·나무만 같은 전체 캔버스 좌표에 남김.
4. water: 강물만 남기고 다리·배 아래 물 표면 복원.
5. structures: 텐트·차량·건물·배·다리·소품만 같은 좌표에 남김.

각 생성본의 미세한 위치 차이를 정규화하고 초안 합성에 사용했다. 원화 권리는 Martin Handford 등 원권리자에게 있으며 별도의 재사용 라이선스를 제공하지 않는다.
