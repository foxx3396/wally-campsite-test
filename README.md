# 캠핑장 숨은그림찾기 · V2

실행 주소: https://foxx3396.github.io/wally-campsite-test/

GitHub Pages에서 실행되는 브라우저 테스트입니다. 설치 없이 위 주소를 열어주세요.

- 배경의 파형 왜곡을 제거하고, 별도로 제작한 캐릭터 4종의 6프레임 동작 적용
- 커피 마시기, 강아지 냄새 맡기, 손 흔들기, 기타 연주
- 캐릭터 바로가기·클릭 반응, 월리 찾기, 힌트, 확대·이동
- AI 리마스터와 기존 원본 비교

배경은 1,526×1,030입니다. 실제 4K가 아니며, 원화의 작은 인물과 세부 표현이 달라졌습니다. 전체 군중 애니메이션이 아닌 캐릭터 4종 테스트입니다.

`node test.cjs`로 로직 검사를 실행할 수 있습니다. 현재 정의서는 `V2-정의서.md`이며 `프로그램정의서.md`는 초기 버전 기록입니다.

원화 출처: https://forocoches.com/foro/showthread.php?t=3846533 . 원저작자 Martin Handford. 해당 이미지의 재사용 라이선스를 제공하는 저장소가 아닙니다.
